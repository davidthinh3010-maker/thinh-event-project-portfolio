# Thinh — Event Project Portfolio

A project-led portfolio for **Đinh Vũ Tiến Thịnh — Event Project Coordinator**.

## Structure
- Hero / positioning
- Profile & working process
- Career + project timeline (2020–2026)
- Featured case studies
- Capabilities
- Contact

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
Import this GitHub repository in Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.
